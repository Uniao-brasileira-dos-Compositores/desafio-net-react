# Student Manager - .NET 8 & React

Desafio técnico para gestão de estudantes com autenticação JWT.

## 🚀 Tecnologias
- **Back-end:** .NET 8 WebAPI, Entity Framework Core (In-Memory), Swagger/OpenAPI.
- **Front-end:** React (Vite), Material-UI, Axios, React Router.

## 🛠️ Como rodar o projeto

### Back-end
1. Navegue até a pasta da API: `cd StudentManager.Api`
2. Execute o comando: `dotnet run`
3. Acesse a documentação: `https://localhost:7092/swagger`

### Front-end
1. Navegue até a pasta do front: `cd student-frontend`
2. Instale as dependências: `npm install`
3. Inicie o projeto: `npm run dev`
